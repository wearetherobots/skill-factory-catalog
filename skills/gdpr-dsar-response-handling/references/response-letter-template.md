# Response letter templates

Open this at Step 6. Fill every bracket; delete guidance in italics. Write in plain language (Art. 12(1)) and in the language of the request where feasible. Never paste the generic privacy notice as a substitute: tailor each heading to this person's data.

## Enclosure guide (the copy)

- Provide a README explaining each file, field names in plain words, codes and abbreviations (CJEU C-487/21: the copy must be intelligible; give whole documents or extracts where context is needed).
- Common structure: `01_account.json`, `02_billing.csv`, `03_support_tickets.pdf`, `04_usage_events.csv`, `05_marketing.csv`, `README.pdf`.
- High-volume logs: give the records, or a faithful extract with the full set available on request; state which you did.
