# Listing QA checklist

Run every section. Record each failure in the QA findings table with Severity (Blocker / Major / Minor).

## 1. Fact consistency
- [ ] Bedroom/bathroom count matches fact sheet and platform settings (half baths called half baths).
- [ ] Bed configuration listed per room; sleeper sofa, futon, air mattress, bunk, crib named as such.
- [ ] "Sleeps X" in title/description = platform max guests = beds can actually sleep X adults (or state which beds are for kids/sofa) = any stated permit/HOA cap. Over cap = Blocker.
- [ ] Square footage, floor count, view claims match photos.
- [ ] Same facts across Airbnb and Vrbo.

## 2. Photo vs claim
- [ ] Every amenity in the copy appears in a photo or the fact sheet.
- [ ] Photos showing items not provided (staged grill, kayaks, decor removed) are flagged.
- [ ] View photos are from the unit, not the rooftop/neighbor/community area, or are captioned as such.
- [ ] Pool/hot tub photos: is it private or shared? Captioned correctly?
- [ ] Seasonal amenities (pool, beach gear, fire pit bans) noted with dates.

## 3. Misleading or prohibited wording
- [ ] Location terms: "beachfront", "oceanfront", "lakefront" only if property directly borders it; otherwise "beach access", "X min walk", "ocean view" (if true).
- [ ] Distances given as measured walk or drive time, not "steps from" / "minutes to" vague claims.
- [ ] Superlatives ("best", "luxury", "#1", "5-star") removed unless substantiated by platform badge the manager confirms.
- [ ] "Fast wifi" only with a measured speed; state the number.
- [ ] "Quiet" removed if fact sheet lists noise sources.
- [ ] "Private" only if not shared with anyone (owner, other units, HOA).
- [ ] "Hot tub" / "heated pool": heating, fees, and hours stated.
- [ ] No party/event marketing; no "bring the whole crew for a celebration" phrasing that implies parties.
- [ ] No phone, email, URL, or instruction to book off-platform.
- [ ] No claims about safety of neighborhood ("safe area") — see fair-housing file.

## 4. Required or expected disclosures
- [ ] Cameras: none indoors (Blocker on Airbnb); every exterior camera and doorbell camera disclosed with general location.
- [ ] Noise/decibel monitors and occupancy sensors disclosed; state they do not record audio if the manager confirms that.
- [ ] Stairs: number of floors, stairs to entry, no elevator, spiral or steep stairs, loft ladders.
- [ ] Pool/hot tub: gated/ungated, unsupervised, depth if known, no lifeguard, seasonal closure.
- [ ] Nearby water, docks, cliffs, balconies without rails.
- [ ] Noise: nightlife, highway, train, airport path, construction, shared walls, HOA landscaping hours.
- [ ] Pets living on property; shared spaces; owner on site.
- [ ] Parking: number of spaces, garage clearance, street/permit rules, steep driveway, 4WD needed in winter.
- [ ] Smoke and CO alarm status consistent with the platform toggle.
- [ ] Required local registration number placed if manager provided one.

## 5. Fair Housing / nondiscrimination
- [ ] Run `fair-housing-language.md` swap table across title, description, rules.
- [ ] Rules apply to conduct and safety, not to who the guest is.
- [ ] Assistance animals not restricted or charged.

## 6. House rules
- [ ] Check-in/out times match platform settings and cleaning schedule.
- [ ] Quiet hours stated with times; note if from HOA/local rule (manager-supplied).
- [ ] Occupancy includes visitors rule (day guests) consistent with max guests.
- [ ] Pet rule: number, size/breed limits, fee, areas off-limits; matches platform toggle.
- [ ] Smoking/vaping/cannabis rule explicit, including outdoor areas.
- [ ] Fines or fees only if the manager confirms they are configured and permitted by the platform; otherwise phrase as "may result in removal per platform policy".
- [ ] No more than ~12 rules; group the rest under Things to Know.

## 7. Tone and readability
- [ ] Opening lines work as a standalone preview.
- [ ] Short paragraphs, room-by-room flow, no wall of text.
- [ ] Rules phrased as clear expectations, not hostile ("Please" over "ABSOLUTELY NO").
- [ ] Consistent brand voice; no excessive emoji.
- [ ] Spelling of local names (neighborhoods, landmarks) checked.
