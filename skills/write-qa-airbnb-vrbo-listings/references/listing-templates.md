# Listing templates and amenity definitions

## Title formulas (pick the strongest true differentiator)
- `[Differentiator] | [Beds]BR [Type], [Secondary feature]`
- `[Beds]BR [Type] in [Neighborhood], [Distance] to [Landmark]`
- `Sleeps [N] | [Feature] + [Feature]`
Use `|`, `+`, `,` to save characters. Count characters including spaces; report the count.

## Description structure
1. **Hook (first 2-3 lines)**: what it is, where, and the top two verifiable reasons to book. Include sleeps N and bed setup if space allows.
2. **The space**: room by room. Each bedroom: bed size, closet, bath (ensuite/hall), AC. Living, kitchen (stove type, dishwasher, coffee maker type), outdoor areas.
3. **Guest access**: what is private, what is shared, what is locked (owner closet, garage), self check-in method.
4. **Neighborhood**: measured walk/drive times to 3-5 named places. No subjective safety claims.
5. **Things to know / disclosures**: stairs, cameras (exterior only), noise, pool safety, parking specifics, seasonal closures, HOA rules, registration number if supplied.

## Amenity definitions (list only when true)
| Amenity | List it when | Do not list when |
|---|---|---|
| Beachfront / Waterfront | Property directly borders the water | Across a road or a walk away |
| Pool | Guests can use it; state private/shared, heated, hours, season | Closed for season without disclosure |
| Hot tub | Working, guest-accessible; state private/shared | "Coming soon" |
| Free parking on premises | Dedicated on-site spaces; state count | Street-only, paid lot |
| EV charger | Installed; state Level 1/2 and connector | Just a regular outlet unless called Level 1 |
| Wifi / Dedicated workspace | Measured speed stated; desk + chair, not a kitchen counter | Unmeasured; couch only |
| Kitchen | Stove/oven or cooktop + fridge + cookware | Microwave and mini fridge only (call it kitchenette) |
| Washer / Dryer | In unit or free on site; state location | Coin-op shared unless stated |
| AC | State central/mini-split/window and which rooms | Fans only |
| Crib / High chair | On site at all times or on request (say which) | "Can buy one" |
| Accessibility features | Supported by photo | No photo |
| Smoke / CO alarm | Installed and working per manager | Unknown (ask) |

Output the amenity list as three groups: **Confirmed**, **Needs verification**, **Do not list (with reason)**.

## House rules template
```
Check-in: after [time] (self check-in via [method])
Checkout: before [time]. Checkout tasks: [max 3 simple tasks, e.g., start dishwasher, take out trash]
Maximum guests: [N], including day visitors. [Visitors rule if any]
Quiet hours: [time]-[time]. [Source: HOA / local rule if manager specified]
No parties or events.
Pets: [allowed? number, size, fee, areas off-limits]. Assistance animals are welcome at no charge.
Smoking and vaping: [not allowed anywhere / allowed only in designated outdoor area]. [Cannabis rule]
Parking: [N] vehicles max; [where]. 
Pool/hot tub: [hours], no lifeguard, children must be supervised by an adult.
Other: [trash/recycling day, fireworks, grills, fire pits per manager]
```
Keep fines out unless the manager confirms they are set up and allowed on that platform.
