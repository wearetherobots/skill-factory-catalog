# Review reply playbook

## Purpose
The public reply is read by future guests. It shows responsiveness and fixes; it does not win the argument with the reviewer and does not change the star rating. Category ratings most affected by replies' credibility: Cleanliness, Accuracy, Check-in, Communication, Value.

## Structure (40-100 words)
1. Thank the guest (first name only, if the manager wants names).
2. Acknowledge the specific issue in neutral words.
3. State the fix only if completed ("We replaced the mattress in the second bedroom"), or the process change ("We've added a second cleaning inspection").
4. Correct factual misstatements gently, once, with a fact future guests can use ("Parking is 2 spaces in the driveway, as noted in the listing").
5. Close warmly; no sales pitch.

## Never include
- Accusations ("you broke", "you lied"), sarcasm, or guest behavior details beyond a neutral fact.
- Refunds, credits, compensation, booking price, or claim details.
- Personal info: last names, number of guests by identity, health, children's details.
- Any offer tied to changing/removing the review (prohibited on both platforms).
- Blame on cleaners or vendors by name.
- Copy-paste replies across reviews.

## Escalate before posting
| Situation | Action |
|---|---|
| Injury, illness, carbon monoxide, fire, pool incident | Minimal neutral reply or no reply until manager/insurer/legal reviews |
| Discrimination allegation | Do not rebut; flag to manager; neutral reply only if approved |
| Review mentions guest's own policy violation (party, extra guests) | Brief factual note on the rule, no details; manager may request platform review |
| Review appears retaliatory, irrelevant, or extortionate | Recommend manager request removal through the platform's review policy process |
| Review names a staff member | Do not repeat the name |

## Response patterns by complaint
- **Cleanliness**: acknowledge, describe the inspection/process change, no blame.
- **Accuracy ("smaller than photos", "not beachfront")**: thank, state the exact fact, and recommend the manager fix the listing copy if the guest has a point. Run Mode B on the listing.
- **Noise**: acknowledge, point to the disclosure if one exists; if none existed, add one to the listing (manager action).
- **Check-in**: explain the fix (new lockbox, updated instructions with photos).
- **Value**: avoid price talk; restate concrete inclusions.
- **Positive review**: thank specifically (mention a detail they liked), 20-50 words, invite back.

## Worked example
**Input:** Airbnb, 3 stars. "Location great but the place was dusty, the hot tub was cold, and the listing didn't mention three flights of stairs. My mom struggled." Internal notes: hot tub heater failed that morning, repaired next day; deep clean added; listing had no stairs disclosure.

**Output:**
> Thank you for staying with us and for the honest feedback. We're sorry the unit wasn't up to standard. The hot tub heater failed the morning you arrived; it has been repaired, and we've added a deep-clean inspection before every check-in. You're right about the stairs: our listing now clearly notes three floors with no elevator so future guests can plan ahead. We appreciate you helping us improve. (69 words)

**Flags for manager:**
- Add "must climb stairs" disclosure and stairs detail in Things to Know (Accuracy risk).
- Confirm the deep-clean process is actually in place before posting.
- Do not mention the guest's mother; reply avoids health details.
- Consider a private message (outside this skill's scope) for follow-up.
