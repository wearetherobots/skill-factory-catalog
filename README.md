# Skill Factory catalog

Public directory of Claude skills generated by [Skill Factory](https://github.com/edbror/skill-factory). Each skill is filed by industry / region / subniche / role in `catalog.json` and in its own `SKILL.md` metadata. The folder layout is flat so the `skills` CLI can find them:

```
skills/<skill-name>/SKILL.md
```

Install one skill:

```sh
npx skills add wearetherobots/skill-factory-catalog --skill <skill-name>
```

Every skill here was machine-generated and passed an automated eval (see `catalog.json` for the score). Review before using it in regulated work.
