# Skill Factory catalog

Public directory of Claude skills generated by [Skill Factory](https://github.com/edbror/skill-factory), organized by industry / region / subniche / role.

```
skills/<industry>/<region>/<subniche>/<role>/<skill-name>/SKILL.md
```

Install one skill:

```sh
npx skills add wearetherobots/skill-factory-catalog --skill <skill-name>
```

Every skill here was machine-generated and passed an automated eval (see `catalog.json` for the score and evidence). Review before using it in regulated work.
